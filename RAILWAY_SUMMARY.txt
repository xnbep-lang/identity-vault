🚀 DEPLOY IN 5 STEPS:

1. Push to GitHub
   git push origin main

2. Go to railway.app
   - Login with GitHub
   - Create project
   - Select identity-vault repo

3. Add PostgreSQL
   - Click "Add Service"
   - Select Database → PostgreSQL
   - Done! (auto-configured)

4. Set Environment Variables
   - PORT=3000
   - NODE_ENV=production
   - JWT_SECRET=<generate>
   - ANTHROPIC_API_KEY=sk-ant-xxx
   - TELEGRAM_BOT_TOKEN=your_token
   - ALLOWED_ORIGINS=https://your-app.railway.app,https://t.me

5. Deploy!
   - Railway auto-deploys when you push to GitHub
   - Or click "Redeploy" in dashboard
   - Get your URL: https://identity-vault-xyz.railway.app

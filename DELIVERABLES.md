## 🎯 How to Use This

### Step 1: Download Everything
All files are in `/mnt/user-data/outputs/`

### Step 2: Choose Your Setup
- **Local Dev:** Use backend/frontend directly
- **Docker:** Use docker-compose.yml
- **Production:** Use deploy.sh or kubernetes files

### Step 3: Configure
- Copy .env.example to .env
- Add your Anthropic API key
- Add Telegram bot token
- Set database URL

### Step 4: Deploy
- Heroku: `./deploy.sh`
- Docker: `docker-compose up`
- Kubernetes: `kubectl apply -f k8s/`
- Traditional: `npm run dev`

### Step 5: Test
- Run tests: `npm test`
- Run attacks: `node run-attacks.js`
- Manual testing in Telegram
